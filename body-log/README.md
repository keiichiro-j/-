# Body Log

食事写真をアップするだけで、AIがカロリー・栄養素(PFC)を自動推定して体系管理をサポートするアプリです。企画書「体系管理アプリ 企画書」の Phase1(個人利用での検証)をベースに、Next.js製のPWAとして実装しています。

## 主な機能

- **食事記録**: 朝食・昼食・夕食・間食の4区分で写真をアップロード(撮影時刻から自動振り分け、手動変更も可)。Claude Vision APIが料理名・推定量・カロリー・PFCをJSON形式で自動推定し、結果は手動で補正可能。
- **ホーム**: 今日の摂取カロリーと目標カロリーとの差分、PFCバランスを表示。
- **グラフ・統計**: 日別・週別・月別のカロリー推移(目標ラインとの比較)、期間のPFC円グラフ、体重の推移。
- **履歴**: カレンダー形式で過去の記録を一覧。食べ過ぎた日・食べなかった日をハイライト。
- **設定**: 目標カロリー/PFC、体重・体脂肪率の記録、表示テーマ(ライト/ダーク/自動)、データのバックアップ(書き出し/読み込み)。

## 技術構成

- Next.js (App Router) / React / TypeScript / Tailwind CSS
- `@anthropic-ai/sdk` による Claude Vision API 呼び出し(`app/api/analyze-meal`)
- `idb-keyval` (IndexedDB) による端末内ローカル保存(Phase1方針: サーバー不要)
- PWA対応(ホーム画面への追加、オフラインでのシェル表示)

## セットアップ

```bash
npm install
npm run generate-icons   # PWAアイコンを scripts/icon-source.svg から生成
npm run dev
```

`.env.example` を `.env.local` にコピーし `ANTHROPIC_API_KEY` を設定すると、食事写真のAI自動解析が有効になります。未設定の場合は自動解析がスキップされ、品目を手動で入力する形になります。

記録データはすべてブラウザのIndexedDBに保存されます(サーバー送信なし)。設定画面からJSON形式でのバックアップ書き出し・読み込みが可能です。

- 和食など品目数が多い料理での画像解析精度の検証
