# YANASE 中古車管理表 整備（フェーズ1：シートの整備）

AU・C7・MB の3社のスプレッドシートそれぞれに同じコードを入れ（コンテナバインド）、**設定アプリ**で会社ごとに設定します。
入力はスプレッドシートへの直接入力です。入力した値は確定した瞬間に正しい書式へ整います（西暦日付・半角カナ・数値＋区切り・km）。
書類の自動読み取り（Gemini）は今後の展望とし、このフェーズのコードには含めていません（下の「今後の展望」参照）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Code.gs` | メニュー、セットアップ、入力時の自動整形（onEdit）、入力チェック、見た目（色分け）、ダッシュボード・仕入集計・販売集計、販売済み移動、車検証リンク、一括整形、ログ |
| `App.html` | 設定アプリ（基本設定・プルダウン選択肢・一括整形・列統一・ログ）。メニューからも Web アプリの URL からも開ける |
| `appsscript.json` | マニフェスト（タイムゾーン・権限・Web アプリの公開設定） |
| `tests/run.js` | 整形・チェックなど純粋ロジックの単体テスト（Node.js、追加依存なし） |

## 導入手順

1. 3社のスプレッドシートのバックアップを取る
2. 「拡張機能」→「Apps Script」を開き、`Code.gs` と `App.html` を同名で作成して貼り付ける
   - 以前の版の `Setup.html`・`Lists.html`・`Cleanup.html`・`Import.html`・`Review.html` が残っていれば削除する
   - プロジェクトの設定で「appsscript.json をエディタで表示」をオンにし、`appsscript.json` を置き換える
3. スプレッドシートを開き直し、メニュー「★専用システム」→「設定アプリを開く」→「基本設定」で会社名を入れて「保存してシートを整える」
   - 以前の版の「設定」シートがあれば、その選択肢を設定アプリへ移してシートを削除します
   - 以前の版の編集トリガー・自動読み取りのトリガーは削除します
4. 「プルダウン選択肢」で担当者などを入力（初期値は案）。他社へは同じ画面の「書き出す／貼り付け」で同じ内容を反映
5. 「一括整形・列統一」でドライラン → 販売済みシートの列統一 → 一括整形

**設定アプリを Web アプリとして開く（任意）**：Apps Script エディタの「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」で公開すると、URL から設定アプリを開けます。
`appsscript.json` は「自分だけがアクセス」（`MYSELF`）にしています。他の人にも使わせる場合は、デプロイ時にアクセスできるユーザーを変更してください。

## 設定アプリ

| タブ | できること |
|---|---|
| 基本設定 | 会社名、車検満了の強調日数、車検証保管フォルダ、シートの状態とOCNの目安（最大 + 1）、セットアップ、書式の整え直し、車検証リンクの更新 |
| プルダウン選択肢 | メーカー（別名つき）・色（別名つき）・担当者・本人確認方法・地域名の編集。保存すると3シートのプルダウンにすぐ反映。3社で共有するための書き出し／貼り付け |
| 一括整形・列統一 | ドライラン → 販売済みシートの列統一 → 書式の一括整形・プルダウン外の値の置き換え |
| ログ | 最近の処理（セットアップ・一括整形・販売済み移動など） |

選択肢はシートではなくスクリプトプロパティに保存します（スプレッドシートに「設定」タブは作りません）。

## 入力時の自動整形と入力チェック

**入力時の自動整形**（シンプルトリガー `onEdit`。セットアップ不要で、誰が入力しても動く。複数セルの貼り付けにも対応）
- 車検満了日・仕入年月日：和暦（R5.6.1、令和5年6月1日など）や「20230601」も西暦の日付にし、`yyyy/MM/dd` で表示
- 初度登録日：年月だけ。「R2.3」「令和2年3月」「2020/3」「202003」などを西暦の年月にし、`yyyy/MM` で表示（日付が入っていても月の1日にそろえる）
- 売上日：年月だけ。入力の仕方・表示（`2026/09`）は初度登録日と同じ
- 車検残：車検満了日から自動で計算（見出し行の ARRAYFORMULA。毎日更新）。H列に値を入れても自動で消して計算を保つ。セットアップ／整え直しで、既存の値・式は自動計算に置き換える
- 走行距離：数字を入れると `12,345km` と表示（「12,345km」と文字で入れても数値に直す）。金額は `1,234,000`
- 入力した列の表示形式は入力のたびに付け直すので、貼り付けで和暦などの表示形式が持ち込まれても西暦・km 表示に戻る
- 全角カナ→半角カナ、全角英数→半角英数、前後の空白を削除（登録番号のひらがなは全角ひらがな、漢字はそのまま）
- 車台番号は大文字化、ハイフンは残す
- プルダウンの列は表記ゆれを選択肢へ変換（例：「メルセデス・ベンツ」→ MB、「ダークブルー」→ 紺）
- OCN は手入力。全角の数字も半角の数値にそろえる（ダッシュボードの在庫数・一覧は OCN が入った行を数える）

**入力チェック（色で知らせる）**
- 赤：OCN・車台番号の重複（3シート横断）、登録番号4項目の組み合わせの重複
- 橙：OCN が数字でない、車台番号・分類番号・一連番号の形式違い、初度登録日が未来、車検満了日が初度登録日以前
- 薄紫（行全体）：車検満了日が近い車両（日数は基本設定で指定）

**ステータス連動**：ステータスを「販売済み」にすると確認のうえ販売済みシートへ移動（見出し名で列を対応づけるので列ずれなし）。確認画面を出せない場合はメニュー「ステータスが販売済みの行を販売済みシートへ移動」から。

**車検証リンク**：車検証保管フォルダでファイル名が OCN で始まるもの（`12345.pdf` など）を行と突き合わせ、「車検証ﾘﾝｸ」を付けます。リンクが入った行（手で貼った場合も）は、ステータスを自動で「名義変更済み」にします（書類待ち・車庫証明申請中・名義変更中・空欄の行だけ。販売済みは変えない。URL を貼ると「車検証ﾘﾝｸ」の表示にそろえる）（設定アプリ・メニューから。1時間ごとの自動更新も選べます）。

**車検証リンクの自動更新**（設定アプリ「基本設定」で間隔を選ぶ：しない／1分ごと（最速）／5・10・15・30分ごと／1時間ごと）
- 車検証保管フォルダに車検証を入れると、選んだ間隔のうちにリンクが付き、ステータスが「名義変更済み」になる（1分ごとなら最大1分ほど）
- スプレッドシートを開いたときにも更新する
- 毎回はフォルダに新しい・更新されたファイルがあるかだけを確認し、あればシートを全件確認する。OCN を入力したときと、1時間に1回も全件確認する（1分ごとでも Apps Script の1日の実行時間を使いすぎないため）
- Apps Script の時間主導トリガーは最短1分で、Google ドライブにファイルが入った瞬間に動く仕組みは無いため、1分ごとが最速

## 計算式の設定（X〜AC列）

設定アプリの「計算式」タブで、下取充当額・リサイクル・下取価格・査定価格・下取損・仕入価格（買取金額）の6列それぞれを設定します。

| 設定 | 動き |
|---|---|
| 未設定 | 今のシートのまま（下取損は空欄のセルにだけ既定の式を置く。入っている値・式は変えない） |
| 手入力 | 入力した値を整形（数値化・区切り表示）。自動計算だった列は、その時点の計算結果を値として残す |
| 自動計算 | 行ごとの計算式で計算（入力した行に自動で式を置く）。その列に入っていた値は消えて計算結果になる（値があったシートは先にバックアップ） |

- 式は `[項目名]`・数字・`%`・`+ - * / ( )` で書く。全角の記号・×・÷・かっこも可。マイナスの数（`-1`）や多重のかっこも書ける
- 端数処理の関数：`四捨五入(式, 桁)`・`切り捨て(式, 桁)`・`切り上げ(式, 桁)`・`整数(式)`・`絶対値(式)`（ROUND・ROUNDDOWN・ROUNDUP・INT・ABS とも書ける。桁は省略で1円単位、-3 で千円単位）
- 例：`[下取充当額]-[下取価格]`、`（[下取充当額]-[下取価格]）÷1.1×0.9`、`切り捨て(（[下取充当額]-[下取価格]）÷1.1×0.9, 0)`、`[査定価格]×(1+10%)`
- 使える項目名：下取充当額・リサイクル・下取価格・査定価格・下取損・仕入価格（買取金額）
- 自分自身を使う式、使えない項目・文字、かっこの数違い、自動計算の列どうしの循環は保存時にエラーで知らせる
- 参照する項目がすべて空欄の行は空欄、0で割るなど計算できない行も空欄
- **区分が「仕入」の行は6列とも手入力**：計算式を置かない（区分を「仕入」に変えると、その行の自動計算の式を外す。別の区分に戻すと式を置き直す）。入力した金額は数値に整え、ダッシュボード・仕入集計の合計に含まれる
- 自動計算の式が入っているセルだけ灰色（条件付き書式の ISFORMULA）。「仕入」の行・手入力の列は白
- 以前の版の見出し行の ARRAYFORMULA は、整え直しのときに行ごとの式へ切り替える
- 自動計算の列に値を入れても自動で消して計算を保つ。見出しのメモに式を表示

## 見た目（視認性）

設定アプリの「保存してシートを整える」「書式・プルダウンだけ整え直す」、メニュー「書式・プルダウン・入力チェックを整え直す」で設定します（値は変えません）。

- **プルダウンの色分け**（条件付き書式）
  - ステータス：書類待ち（赤）→ 車庫証明申請中（黄）→ 名義変更中（青）→ 名義変更済み（緑）→ 販売済み（灰）
  - 区分：買取・仕入・下取・オークションを4色で
  - 色：黒・白・灰・赤・紺・青・緑・黄・茶を実際の色で塗る
  - 車種・担当・本人確認方法・地域：値が入ると淡い青
  - Apps Script ではプルダウン（チップ）そのものに色を付けられないため、セルの色で表しています
- **見出し**：車両・仕入・登録番号・状況／販売・金額のまとまりごとに色分け、白の太字、入力のしかたをメモで表示
- **自動入力の列**：実際に自動で入る列だけ本文を灰色にする（見出しの色はそのまま）。対象は、車検残（列全体）、自動計算の式が入っている金額のセル（区分「仕入」の行は手入力なので白）、車検証保管フォルダを設定しているときの車検証リンク。手入力のままの列は灰色にしない。条件付き書式なので1行おきの色より上に表示
- **本文**：1行おきに色、配置（日付・選択肢は中央、数値は右）をそろえる
- **折り返しなし・列幅**：見出し・本文とも折り返さない。列幅は「書式・プルダウンを整え直す」のときだけ文字が収まる幅に合わせる（標準の幅より狭くはしない）。入力のたびには変えない（画面がずれないように）
- 見出し行と A〜B列（仕入年月日・OCN）を固定、見出しにフィルタ、タブの色分け（輸入車・国産車・販売済み・ダッシュボード・仕入集計・販売集計・ログ）
- 優先順：入力チェックの色（重複・形式違い）→ プルダウンの色 → 車検満了間近の行の色 → 自動入力の列の灰色

## ダッシュボード

「ダッシュボード」タブ（先頭）に、輸入車マスタ・国産車マスタ（在庫）から自動で集計して表示します。すべて数式なので、入力するとすぐ反映されます。

1. **ステータスごとの台数**：書類待ち・車庫証明申請中・名義変更中・名義変更済み・在庫合計のカード。台数、在庫に占める割合（棒と％）、在庫合計には輸入車／国産車の内訳
2. **名義変更済み以外の車両の一覧**：OCN が入っている在庫のうち、名義変更済み以外（ステータス未入力は「未入力」）。ステータスの流れ順 → 仕入が古い順。ステータス・仕入からの経過日数・仕入年月日・OCN・輸入／国産・車種・モデル名・車台番号・仕入先（該当者）・担当・区分・車検満了日。経過日数が31日以上は橙、61日以上は赤

- タイトル行は固定表示。シートは整え直しのたびに作り直すため、直接編集しないでください（編集すると警告が出ます）

## 仕入集計

「仕入集計」タブ（ダッシュボードの隣。メニュー「仕入集計を開く」）に、販売済みを含む3シートの全車両を仕入年月日で集計して表示します。すべて数式なので、入力するとすぐ反映されます。

1. **集計期間**：上の「開始日」「終了日」をカレンダーから選ぶ（両端の日を含む。1か月分なら 10/01〜10/31 のように選ぶ。作り直しても選んだ期間は残る。この2つのセルだけは警告なしで変更できる）。横に期間（例：2026/10/01 〜 2026/10/31（31日間））を表示し、終了日が開始日より前だと警告
2. **期間の合計カード**：仕入台数・仕入価格・査定価格・下取価格・下取充当額・リサイクル・下取損の合計と、「前の同期間」（直前の同じ日数の期間。例：10/1〜10/31 なら 8/31〜9/30）の数字
3. **期間に仕入れた車両の一覧**：仕入年月日・OCN・シート（輸入車／国産車／販売済み）・ステータス・車種・モデル名・区分・担当・仕入先・登録番号（地域・分類番号・ひらがな・一連番号をつなげて表示）・下取充当額・リサイクル・下取価格・査定価格・下取損・仕入価格（買取金額）。仕入年月日 → OCN の順。一覧のすぐ上に合計行（台数と金額の合計）。0 は「–」で表示

- 名義変更済み以外の一覧と同じく、期間を変えると一覧がその期間の車両に絞り込まれます
- タイトル行は固定表示。直接編集しないでください（編集すると警告が出ます）

## 販売集計

「販売集計」タブ（仕入集計の隣。メニュー「販売集計を開く」）に、販売済みシートの車両を売上日の月で絞り込んで表示します。すべて数式なので、入力・販売済みへの移動がすぐ反映されます。

1. **集計期間**：上の「開始月」「終了月」をプルダウンから選ぶ（2026/10 の形。売上日は年月だけなので月単位。両端の月を含む。1か月だけなら同じ月を選ぶ。作り直しても選んだ月は残る）。横に期間（例：2026/07 〜 2026/09（3か月））を表示し、終了月が開始月より前だと警告。プルダウンは最も古い売上日（無ければ2年前）から今月の6か月先まで
2. **期間の合計カード**：販売台数・仕入価格・査定価格・下取価格・下取充当額・リサイクル・下取損の合計と、「前の同期間」（直前の同じ月数。例：7〜9月なら4〜6月）の数字
3. **期間に販売した車両の一覧**：売上日・OCN・車種・モデル名・区分（色つき）・売上先・担当・仕入年月日・仕入先・登録番号・下取充当額・リサイクル・下取価格・査定価格・下取損・仕入価格（買取金額）。売上日 → OCN の順。一覧のすぐ上に合計行

- 販売済みシート自体は、マスタと同じ列構成のデータの置き場所のまま（行の移動や列統一のため）。見るときは販売集計タブを使う
- タイトル行は固定表示。直接編集しないでください（編集すると警告が出ます。開始月・終了月だけは自由に変更できる）

## 既存データの一括整形と列統一

設定アプリの「一括整形・列統一」。まずドライランで変更予定を確認してから実行します。実行前に対象シートのバックアップ（`シート名_BK_日時` の非表示シート）を自動で作ります。

1. 販売済みシートの列統一：現行の列配置 → A〜AC（標準にない列はAD列以降に残す）
2. 書式の一括整形：入力時の自動整形と同じ規則で全セルを整え、最後に全列の表示形式（西暦・km・区切り）を整え直す
3. プルダウン外の値の洗い出し：値ごとに置き換え先（候補を自動選択）／そのまま／選択肢に追加を選ぶ
4. 計算式の保護：計算式の列（車検残・下取損・仕入価格）と式の入ったセルは対象外
5. 結果レポート：変更したセル数・修正できなかったセルをログに記録

## 未確定事項とコード上の変更箇所

| 確認事項 | 変更箇所 |
|---|---|
| 現行「販売済み」シートの見出し行 | 一括整形の列統一の対応表で確認。別表記は `FIELDS` の `aliases` に追加 |
| 計算式の列と式の内容 | `FORMULA_DEFS`（車検残は車検満了日までの残り日数で常に自動計算。下取損は暫定式。仕入価格は未定義。下取損・仕入価格は既存の式をそのまま使う） |
| 「買取金額」が仕入価格（AC列）と同じ項目か | 同じ前提で AC列の見出しを「仕入価格（買取金額）」にしています |
| プルダウンの選択肢・メーカー表記ルール | 設定アプリの「プルダウン選択肢」。初期値は `DEFAULT_LISTS` |
| 自社名義変更後の車検証リンク用の列（AD列） | 未対応。追加する場合は `FIELDS` に列を足し、`updateCertLinks` で `OCN_自社名義` のファイルを対応づける |
