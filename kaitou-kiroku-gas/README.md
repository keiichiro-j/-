# 資格試験 解答記録アプリ（GAS実装）

`資格試験解答アプリ_企画書.md` の「②ショートカット起動のWebアプリ方式」（8. 実装方式）をベースにコード化した
Google Apps Script プロジェクトです。GoogleスプレッドシートをDBとし、GASの HTML Service で
レスポンシブなWebアプリ（iPhone・PC共通URL）を提供します。

## 画面構成（企画書 6.）

1. **セット一覧画面**（`html/Index.html` `#screen-home`）: 解答セットの新規作成・過去セットの選択
2. **設定画面**（`#screen-setup`）: 問題数・出題形式（一括設定＋問題ごとの個別上書き）
3. **解答入力画面**（`#screen-answer`）: 問題ごとの解答欄（選択式ボタン／記述式テキスト）＋備考欄。入力は自動保存
4. **採点・結果画面**（`#screen-result`）: 正解入力→選択式は自動採点、記述式は○／△／✕の自己申告。正答率・不正解一覧・備考の振り返り
5. **アプリ設定画面**（`#screen-settings`）: テーマ（ライト／ダーク／端末設定に追従）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Constants.gs` | シート名・列定義・出題形式／判定区分などの定数 |
| `ScoringService.gs` | 外部サービス非依存の純粋ロジック（出題形式の組み立て、正誤判定、正答率集計）。`tests/run.js` の対象 |
| `SheetService.gs` | スプレッドシートの自動作成・シート初期化・行の読み書き基盤 |
| `Api.gs` | クライアント（HTML）から `google.script.run` で呼び出すAPI（セットのCRUD、解答保存、採点保存、テーマ設定） |
| `Code.gs` | `doGet` エントリポイント |
| `html/Index.html` `html/Stylesheet.html` `html/JavaScript.html` | 5画面のSPA。Apple純正アプリ風のミニマルなUI（企画書 7.） |
| `tests/run.js` | `ScoringService.gs` の単体テスト（Node.js, 追加依存なし） |

## データモデル（スプレッドシート）

初回アクセス時に「資格試験解答記録アプリ_DB」という名前のスプレッドシートが自動作成され、
そのIDが Script Properties（`SPREADSHEET_ID`）に保存されます。以後は同じスプレッドシートを使い続けます。

- **Sets シート**: 解答セット単位の行（id・試験名・問題数・ステータス・回答済み数・採点済み数・正解数・正答率・作成/更新日時）
- **Answers シート**: 1解答セット × 1問題 = 1行（setId・問題番号・出題形式・選択肢数・解答・正解・備考・判定・更新日時）

## セットアップ手順

1. **claspでのデプロイ**
   ```bash
   cd kaitou-kiroku-gas
   npm i -g @google/clasp
   clasp login
   clasp create --type webapp --title "解答記録"
   clasp push
   ```
2. **Webアプリとして公開**
   - `clasp deploy` または GASエディタの「デプロイ」→「ウェブアプリ」
   - `appsscript.json` の `webapp.access` は既定で `MYSELF`（本人のみ利用）としています。個人利用の範囲を超える場合は変更してください
3. **スプレッドシートの準備は不要**
   - 初回アクセス時にDB用スプレッドシートが自動作成されます（手動でのシート作成・ID設定は不要）
4. **iPhoneのショートカット設定**（企画書 9.）
   - 「ショートカット」アプリで「Webサイトを開く」アクションにデプロイ後のWebアプリURLを設定し、ホーム画面に追加する
   - 独自アイコン・起動画面にしたい場合は、ショートカットの共有シートから「ホーム画面に追加」を使うとサイトアイコンをカスタマイズできる

## テスト

外部サービス（Spreadsheet等）に依存しない純粋ロジック（出題形式の一括設定＋個別上書きの組み立て、
選択式の自動採点、記述式の自己採点集計、正答率計算）を Node.js の `vm` サンドボックスで検証します。

```bash
npm test
```

## 実装上の簡略化・今後の検討事項（企画書 9. に対応）

- **テーマ設定の保存先**: Script Properties（本人のみのアクセスのため、端末をまたいで同期されます）。ローカルにも `localStorage` でキャッシュし、初回描画のちらつきを防止しています
- **自動保存**: 解答・備考の入力はデバウンス（約0.7秒）でサーバーへ保存し、画面離脱時・タブ非表示化時にも即時保存します。オフライン時の下書きローカル保持（端末内キャッシュ）は未実装のため、電波が不安定な環境では保存タイミングにご注意ください
- **分野別（カテゴリ別）の正答率集計**: 未実装（今後の検討事項）
- **複数資格の管理方法**: 現状はセット一覧をすべて時系列で表示。資格ごとのフォルダ分け・絞り込みは未実装
- **記述式の自己採点基準**: ○／△／✕の3段階。点数式への変更は未実装
- **過去の受験結果の推移グラフ**: 未実装（一覧画面のスコアバッジで簡易的に確認可能）
