# コーディネーター

天気・シーン（TPO）・手持ちの服・着用履歴から、AIが「今日のベストな一着」を提案するパーソナルコーディネートアプリです。
「その日のコーデ」企画書のフェーズ1〜2相当をNext.js製PWAとして実装しています。

## 主な機能

- **ワードローブ（クローゼットDB）**：服を写真付きで登録・管理（ブランド名／アイテム名／カテゴリ／サイズ〈ドロップダウン〉／色／季節〈複数選択可〉／シーン／ステータス）
- **AIコーデ提案**：天気・シーン・在庫・直近の着用履歴・世界観設定を踏まえて2〜3パターンを提案。色・素材・ブランドなどアイテムごとの特徴を踏まえ、パターンごとに言い回しを変えた理由文を表示
- **フィードバック学習の土台**：「良い／微妙」評価を記録し、次回以降の提案スコアに反映
- **アーカイブ（履歴・お気に入り）**：カレンダーで振り返り、お気に入りコーデを再提案リクエスト
- **プロフィール**：身長・体重・顔写真（任意）からパーソナルカラーを簡易診断し、提案に反映
- **資産管理**：ワードローブ内アイテムのリセール価格を概算し、総資産額・アイテム別の写真付き一覧（スクロール表示）を表示
- **出品サポート**：アイテムごとにフリマアプリ向けの出品文（タイトル・本文）を自動生成し、コピーして利用可能。写真がある場合はAIが写真のディテールも参照。価格は含まないため出品前に必ず内容確認を促す表示あり
- **設定**：好みの世界観（ストリート／トレンド／クラシック等、複数選択可）を設定し提案に反映。顔写真からの髪型診断、アプリについて／利用規約／プライバシーポリシー／お問い合わせ（準備中）／ローカルデータ削除
- **試着室（2Dプレビュー）**：身長から簡易スケールした人型シルエットに、顔写真・登録した服の写真を重ねて表示する簡易試着プレビュー（本格的な3D試着ではなく2Dの簡易プレビューです）
- **次に買うべきアイテム提案**：カテゴリ・季節・シーンの偏りを分析し、優先度の高い購入候補を最大3件表示
- **PWA**：ホーム画面に追加してアプリのように起動（マニフェスト・アイコン・オフラインシェル対応）

## 技術構成

| 役割 | 実装 |
|---|---|
| フロントエンド | Next.js 16 (App Router) / React 19 / Tailwind CSS v4 |
| データ保存 | ブラウザの IndexedDB（`idb-keyval`）※フェーズ1は端末内保存。Firebase移行は将来フェーズ |
| 天気情報 | [Open-Meteo](https://open-meteo.com/)（APIキー不要） |
| AIコーデ提案・パーソナルカラー診断 | `ANTHROPIC_API_KEY` 設定時は Claude API を呼び出し、未設定時は同梱のルールベースロジックにフォールバック |
| PWA | `app/manifest.ts` + `public/sw.js`（オフラインシェルキャッシュ） |

服の写真・顔写真・身長体重はすべて端末のIndexedDBにのみ保存され、外部には送信されません（AI提案・診断でClaude APIを利用する場合を除く）。

## セットアップ

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。スマホのブラウザで開き、共有メニューまたはブラウザメニューから「ホーム画面に追加」するとアプリのように起動できます。

### 環境変数（任意）

`.env.local` を作成し、Claude APIによるAIコーデ提案・パーソナルカラー診断を有効化できます（未設定でもルールベースロジックで動作します）。

```bash
cp .env.example .env.local
```

```
ANTHROPIC_API_KEY=sk-ant-...
```

### アイコンの再生成

アプリアイコンは `scripts/icon-source.svg` から生成しています。デザインを変更した場合は以下で再生成してください。

```bash
node scripts/generate-icons.mjs
```

## 企画書との対応・今後の展開

- **フェーズ1（個人利用）**：本リポジトリで実装済み（クローゼットDB／AIコーデ提案／履歴・お気に入り／プロフィール・資産管理）
- **フェーズ2以降（招待制・一般公開）**：Firebase Authentication / Firestore / Storage への移行、通知機能、Googleカレンダー連携、リセール相場の外部データ連携などが未実装です
- リセール価格はカテゴリ・ブランド帯・状態から算出した**概算値**であり、実際のフリマ相場APIには接続していません（企画書6章の代替案に対応）
- パーソナルカラー診断は `ANTHROPIC_API_KEY` 未設定時、簡易的な仮診断を表示します
