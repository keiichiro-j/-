# OFF PRODUCT コーポレートサイト — WordPressオリジナルテーマ

添付いただいた2つの資料

1. `OFF_PRODUCT_design_proposal.docx`（地下茎／ブラッシュドシルバー×グロースグリーンのデザイン提案書）
2. `OFF_PRODUCT_website_preview_1.html`（ダークトーン・Bentoグリッドのプレビュー実装）

を統合し、さらに洗練させたデザインで実装したWordPressオリジナルテーマです。

- **コンセプトは提案書（地下茎／ブラッシュドシルバー×グリーン）を正**とし、明るいシルバートーンの背景に統一
- **プレビューHTMLの構造（sticky＋ぼかしヘッダー、カードシステム、モノスペースのラベル、Bento風レイアウト）を継承**しつつ、ヒーローのビジュアルは提案書の要求どおり「地下茎（ロゾーム）ダイアグラム」に置き換え
- 実績（Works）は固定ページのハードコードではなく**カスタム投稿タイプ**にして、WordPress管理画面から追加・編集できるように拡張
- 会社概要・見出しコピー・CTAリンクは**カスタマイザー**から編集可能（コードを触らずに更新できます）

## 1. ファイル構成

```
off-product-wordpress/
└── theme/
    └── off-product/              ← このフォルダをまるごとZIP化してWordPressにアップロードします
        ├── style.css              テーマ情報 + 全体スタイル（配色・フォント変数はここ）
        ├── functions.php          テーマ初期化・スクリプト読込・CPT/カスタマイザー読込
        ├── header.php             ヘッダー（sticky nav・ハンバーガーメニュー）
        ├── footer.php             フッター（お問い合わせCTA）
        ├── front-page.php         トップページ本体（ヒーロー〜会社概要まで全セクション）
        ├── index.php              フォールバック（ブログ一覧など）
        ├── page.php               固定ページ用テンプレート
        ├── single-works.php       実績の詳細ページ
        ├── archive-works.php      実績の一覧ページ（/works/）
        ├── inc/
        │   ├── cpt-works.php      「実績（Works）」カスタム投稿タイプ＋進行状況メタボックス
        │   └── customizer.php     カスタマイザー項目（見出し・会社情報・CTA）の定義
        └── assets/js/main.js      ハンバーガーメニュー・スクロールリビール・地下茎アニメーション
```

## 2. 導入手順（レンタルサーバー／WordPress管理画面での作業）

### 手順1：テーマをZIP化する

```bash
cd off-product-wordpress/theme
zip -r off-product.zip off-product
```

### 手順2：WordPressにテーマをアップロード

1. WordPress管理画面にログイン
2. `外観 > テーマ > 新規追加 > テーマのアップロード`
3. 先ほど作成した `off-product.zip` を選択してインストール
4. インストール後、「有効化」をクリック

> レンタルサーバーにFTP/SFTPでアクセスできる場合は、`off-product` フォルダをそのまま
> `wp-content/themes/off-product/` にアップロードしても構いません。

### 手順3：固定ページ「トップページ」を作成し、フロントページに設定

このテーマの `front-page.php` は、WordPressの「フロントページ表示設定」が
**「固定ページ」**になっているときに自動的に使われます。

1. `固定ページ > 新規追加` で「トップページ」という空のページを1つ作成し公開（本文は空でOK。front-page.phpが内容を出力します）
2. `設定 > 表示設定` を開く
3. 「ホームページの表示」を **「固定ページ」** に変更し、「ホームページ」に手順1で作成したページを選択
4. 保存

### 手順4：パーマリンク設定

`設定 > パーマリンク` で「投稿名」を選択して保存してください
（実績の詳細URLが `/works/作品名/` のような形になり、SEO的にも綺麗になります）。

### 手順5：メニューの作成（任意）

メニューを作らなくても、ヘッダーには自動的に
「事業内容／実績／開発の流れ／会社概要」のフォールバックメニューが表示されます。
文言を変えたい場合のみ：

1. `外観 > メニュー > 新規メニューを作成`
2. 「事業内容」→リンク `#service`、「実績」→ `#works`、
   「開発の流れ」→ `#process`、「会社概要」→ `#company` を追加
3. 「メニュー位置」で **「メインナビゲーション」** にチェックを入れて保存

### 手順6：ロゴの設定（任意）

`外観 > カスタマイズ > サイトアイデンティティ > ロゴを選択` から画像ロゴをアップロードできます。
未設定の場合は「● OFF PRODUCT」というテキストロゴが自動表示されます。

## 3. コンテンツの編集手順

### 3-1. キャッチコピー・会社情報・お問い合わせ先を編集する

`外観 > カスタマイズ` を開くと、以下のセクションがあります。

| セクション | 編集できる内容 |
|---|---|
| ヒーローエリア | メインの見出し・リード文・CTAボタンの文言とリンク先 |
| フィロソフィー | 「PRODUCTをOFFにする」帯エリアの見出し・本文 |
| 会社概要 | 会社名・事業内容・設立・所在地・代表者（空欄は自動で「ご記入ください」表示） |
| お問い合わせ | フッターの見出し・ボタン文言・リンク先（`mailto:` またはお問い合わせフォームのURL） |

見出しの入力欄では次の記法が使えます。

- 改行したい箇所に `\n` を入力
- 色を変えたい範囲を `{{grad}}〜{{/grad}}` で囲むと、グリーンのグラデーション文字になります
  （例: `アイデアを、\n迷わず使える{{grad}}プロダクト{{/grad}}へ。`）

### 3-2. 実績（Works）を登録する

1. 管理画面左メニューの **「実績（Works）」> 新規追加**
2. タイトル・本文（詳細説明）・アイキャッチ画像を設定
3. 右サイドバーの「進行状況」で **企画中／開発中／公開中** を選択
4. 公開すると、トップページの「開発実績・プロダクト」セクションに自動でカード表示されます
   （未公開の場合は元のプレビュー同様、点線プレースホルダーが表示されます）

### 3-3. お問い合わせフォームを設置する

`contact_button_url` はデフォルトで `mailto:info@example.com` になっています。
実際の受付フローに合わせて、以下のいずれかに変更してください。

- **メールで受ける場合**: カスタマイザーの「お問い合わせ」→リンク先を `mailto:実際のアドレス` に変更
- **フォームで受ける場合**: [Contact Form 7](https://ja.wordpress.org/plugins/contact-form-7/) 等をインストールし、
  固定ページ「お問い合わせ」を作成してショートコードを設置、カスタマイザーのリンク先をそのページURLに変更

## 4. デザインをさらに調整したい場合

すべての配色・余白・フォントは `style.css` 冒頭の CSS変数にまとまっています。

```css
:root{
  --paper:#F7F7F4;      /* ページ背景（シルバー50） */
  --silver-300:#D8DAD1; /* 罫線・カード枠 */
  --silver-500:#9DA195; /* 未確定ノード・サブテキスト */
  --ink:#232821;        /* 本文・見出しテキスト */
  --ink-dark:#171613;   /* フィロソフィー帯・フッターの背景 */
  --green:#3E7A49;      /* グロースグリーン（アクセント最小限） */
  --green-deep:#2C5A36; /* ディープグリーン（見出しアクセント） */
}
```

- フォントは `functions.php` の `off_product_assets()` でGoogle Fontsから読込（Outfit / Inter / JetBrains Mono / Noto Sans JP）
- ヒーローの地下茎ダイアグラムは `front-page.php` 内のインラインSVG（`<svg class="rhizome-svg">`）で、
  ノードの数や配置はパス（`d="..."`）と `<circle>` の座標を書き換えるだけで調整できます
- 新規事業が決まった際は、`.node-next` の1つを `.node-live` にクラス変更するだけで
  「芽吹いた状態」に切り替えられます（提案書07 / SCALABILITY の想定どおりです）

## 5. 公開前チェックリスト

- [ ] 会社概要（設立・所在地・代表者）をカスタマイザーで入力した
- [ ] お問い合わせボタンのリンク先を実際の連絡手段に変更した

- [ ] `設定 > 表示設定` でフロントページが正しく設定されている
- [ ] `設定 > パーマリンク` を保存した
- [ ] SSL（https）が有効になっている
- [ ] SEOプラグイン（例: Yoast SEO / SEO SIMPLE PACK）でメタディスクリプション・OGP画像を設定した
- [ ] スマートフォン表示でハンバーガーメニュー・ヒーロー・実績カードの崩れがないか確認した

## 6. 補足：推奨環境

- WordPress 6.0以降 / PHP 7.4以降（テーマの `Requires` に準拠）
- レンタルサーバーは国内の主要WordPress対応プラン（エックスサーバー・ConoHa WING等）であれば追加設定不要です
- ローカルで確認したい場合は [Local](https://localwp.com/) や [DevKinsta](https://kinsta.com/devkinsta/) 等のローカル環境ツールに
  上記テーマフォルダを配置して動作確認できます
