# Google ログインと記録（GAS）

遊ぶ人を Google アカウントで見分けて、次の2つを行う。

1. **本人のセーブを本人の Google アカウントに保存**（別の端末・別のブラウザでも続きから遊べる）
2. **作った人のスプレッドシートに全員の記録を残す**（プレイヤー一覧・クリア記録・ステージごとのベスト）。ゲーム内の「記録 → 番付」にはニックネームとタイムだけを出す（メールは出さない）

GAS の外（ファイルを直接開いた時・claude.ai のページ）では今までどおり端末のブラウザにだけ保存する。

## しくみ（2つのプロジェクト）
| プロジェクト | ファイル | デプロイ | 役目 |
|---|---|---|---|
| ゲーム | Code.gs, index.html, appsscript.json | 実行：ウェブアプリにアクセスしているユーザー／アクセス：Google アカウントを持つ全員 | 遊ぶ人の Google アカウントで動く。本人のセーブを UserProperties に保存。Google の ID トークン（本人の証明）を付けて記録係に送る |
| 記録係 | Recorder.gs, appsscript.json（recorder.appsscript.json の中身） | 実行：自分／アクセス：全員 | スプレッドシートに付けた Apps Script。ID トークンを Google（tokeninfo）で確かめてから書く。遊ぶ人はほかの人になりすませない |

2つに分ける理由：1つのプロジェクトにすると、遊ぶ人全員に「スプレッドシートを編集する権限」を求めることになるため。分けると、遊ぶ人が許可するのは「メールアドレスを見る・外部につなぐ」だけ、スプレッドシートを触る権限は作った人の記録係だけになる。

## 作り方（作った人が1回だけ）
1. **記録係**：新しいスプレッドシートを作る → メニュー「拡張機能 → Apps Script」→ `Recorder.gs` を貼る。「プロジェクトの設定」で appsscript.json を表示して `recorder.appsscript.json` の中身を貼る → 保存 → 関数 `setup` を実行（許可を求められたら許可）→ シート「プレイヤー」「クリア記録」「ベスト」ができる
2. 記録係を「デプロイ → 新しいデプロイ → ウェブアプリ」（実行：自分、アクセス：全員）→ 出た URL（…/exec）を控える
3. **ゲーム**：別の新しい Apps Script プロジェクトに `Code.gs`・`index.html`（HTML ファイル名は index）・`appsscript.json` を貼る。`Code.gs` 先頭の `RECORDER_URL` に 2 の URL を貼る → 保存
4. ゲームで関数 `showGameId` を実行 → ログに出た値を、記録係の `Recorder.gs` 先頭の `GAME_AUD` に貼る → 記録係を「デプロイを管理 → 編集 → 新バージョン」で更新
5. ゲームを「デプロイ → 新しいデプロイ → ウェブアプリ」（実行：ウェブアプリにアクセスしているユーザー、アクセス：Google アカウントを持つ全員）→ この URL を遊ぶ人に送る

## 遊ぶ人から見ると
- はじめて開くと Google のログインと、権限の確認（メールアドレス・外部サービスへの接続）が出る。個人で作ったアプリなので「Google で確認されていません」と出ることがある（「詳細 → 移動」で進める）
- タイトルで「ランキングに出す名前」を聞かれる（あとで左下の「Google：名前 ✎」から変えられる）
- **LINE のトーク内のブラウザでは Google のログインができない**（Google の決まり）。LINE で送る時は「Safari／Chrome で開いてください」と添える

## 記録される内容（スプレッドシート）
- プレイヤー：ID（Google のアカウント番号）、メール、ニックネーム、はじめて／さいごに遊んだ日時、保存回数、クリアしたステージ、宝珠、さるぼぼ、持ちコイン、称号数、武器数、いつものキャラ
- クリア記録：日時、ID、メール、ニックネーム、ステージ、タイム、キャラ、ミス、コイン、武器、判定（ありえない速さは「対象外」）
- ベスト：ステージ×人ごとのベストタイム（番付に使う）
