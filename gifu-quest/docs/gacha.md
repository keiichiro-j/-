# 福引き蔵（武器ガチャ）仕様

ワールドマップの「福引き」から入る。ステージで集めたコインで、ガラガラ抽選器（福引き）を回して武器を手に入れる。**現実のお金は使わない。**

## 引き方
| 種類 | 費用 | 備考 |
|---|---|---|
| 今日の無料 | 0 | 1日1回。端末の日付が変わる（0時）と戻る。マップのボタンに赤い点 |
| 1回 | コイン100枚 | |
| 10回 | コイン900枚 | 特上以上が少なくとも1つ出る |

コインはステージで拾った分が持ちコインに貯まる（1ステージ約110枚）。

## レアリティ（4段階）と確率
| 段階 | 星 | 確率 | 種類 | 玉の色 | 最大レベル後の換金 |
|---|---|---|---|---|---|
| 並 | ★ | 55% | 10 | 白 | 10枚 |
| 上 | ★★ | 30% | 9 | 青 | 30枚 |
| 特上 | ★★★ | 12% | 7 | 赤 | 80枚 |
| 極 | ★★★★ | 3% | 4 | 金 | 200枚 |

- 天井：50回のうちに極が出なければ、50回目は必ず極。極が出ると数え直し
- 確率は画面の「確率を見る」でいつでも見られる
- 同じ武器が出るとレベルが上がる（最大Lv5）。Lv5のあとは表の枚数のコインに替わる

## 武器（30種）
データは src/data/weapons.json。どのキャラでも1つ装備できる（「持ち物」タブ）。効果は数値がレベルで伸び（Lv1=×1.0〜Lv5=×1.6）、「得意なキャラ」が持つとさらに×1.25。
効果の種類：攻撃（技・踏みつけ以外のダメージ倍率）、技の待ち時間、速さ、ジャンプ（上限+10%）、ハート、コイン吸い寄せ、コイン2倍の確率、無敵時間、踏みつけダメージ、技が貫く、技の範囲、守り（中間地点ごとに攻撃を防ぐ回数）、敵を倒すと回復、刃の波（技と一緒に飛ぶ）。
ステージの設計（最も跳べないゲンで越えられる）を壊さないよう、ジャンプ+10%・速さ+20%・待ち時間-50% を上限にしている。

## 実装
- 計算：src/systems/gacha.js（pull / rollRarity / weaponEffects。DOMなし。tests/gacha.test.js）
- 画面：src/scenes/gacha.js（福引き・持ち物・確率表・めくり演出）。通しテスト tests/e2e/gacha.mjs
- 効果の反映：src/actors/player.js（stats・守り・刃の波）, projectiles.js（貫く・範囲・WaveShot）, systems/pickups.js（吸い寄せ・2倍・無敵）, world/world.js（踏みつけ・回復）
- 絵：src/art/weapons.js（weapon_<id>、48×48、中心基準）
- セーブ v3：weapons { id: { lv } }, equipped, gacha { lastFree, pity, total }
