# GIFU OPEN ROAD 3D 設計書（Claude Code向け）

Nov 23, 2026 · @

## 1. 概要

架空の岐阜を舞台に、GASだけで配信できるローポリ3Dのオープンワールド・アクションを作る。現行プロトタイプ（index.html 1ファイル・約1,900行）の構成を土台に、モジュール分割・人と車のリアル化・武器と戦闘・GTA系の主要システムを段階的に実装する。

**前提条件**

- 配信：Google Apps Script のWebアプリ（HtmlService）。サーバー処理はセーブ・ランキング・設定のみ
- 描画：three.js r128（現行と同じ版に固定。CDN読み込み、将来はGAS内に同梱できる構成にする）
- 対象：PC（キーボード＋マウス）とスマホ横向き（タッチ）。ゲームパッドは任意対応
- 性能目標：PCで60fps、中位スマホで30fps以上
- 舞台：岐阜をモチーフにした架空の街。実在の企業名・店名・人物は使わない
- 権利：GTAの名称、ロゴ、UIデザイン、音楽、キャラクターは使わない。遊びの構造のみ参考にする

**表現方針**

- 暴力表現はコミカル寄り。血・肉体欠損・残虐な演出は入れない
- 撃たれた／はねられたNPCは倒れて一定時間後に消える（死体の放置・損壊なし）
- 「表現レベル」設定（ふつう／マイルド）を用意し、マイルドでは武器を水鉄砲・ペイント弾などに差し替えられるようにする

**現行プロトタイプから引き継ぐもの**

- タイル地図生成（140×100タイル、1タイル＝4m）、地区判定、ミニマップ
- 地面テクスチャ方式、建物の結合メッシュ、窓の発光、木と街灯のインスタンス描画
- 歩行者のインスタンス描画（部位ごとのInstancedMesh）
- 左側通行の交通AI、手配度と警察、ミッション、昼夜、PC/スマホ操作

## 2. 技術アーキテクチャ

開発はローカルのESモジュールで行い、ビルドで1枚のindex.htmlにまとめてから clasp でGASへ送る。実行時はGASは配信と保存だけを担い、ゲームの処理はすべてブラウザで動かす。

**ループの順序（1フレーム）**

1. 入力を収集して「操作コマンド」に変換（キーボード、タッチ、パッドを同じ形に揃える）
2. 物理は固定ステップ60Hz（アキュムレータ方式、最大5ステップ/フレーム）で車両・弾・ラグドールを進める
3. AIは負荷分散のため「近いものは毎フレーム、遠いものは数フレームおき」に更新（LOD）
4. システム（手配度、ミッション、経済、昼夜・天候）を更新
5. 描画用の行列を書き出し、three.jsで描画、最後にHUD（2Dキャンバス）を重ねる

| 項目 | PC | スマホ |
| --- | --- | --- |

| 描画ポリゴン | 30万以下 | 15万以下 |

端末判定は初回起動時に3秒の簡易ベンチマークを取り、「高／中／低」のプリセットを自動で選ぶ（設定画面で変更可）。

**データ保存**

- セーブ：端末内（localStorage）に自動保存。将来、GAS側に「引き継ぎコード」方式のクラウド保存を追加
- ランキング：google.script.run でスプレッドシートへ書き込み。匿名ID＋1分あたりの送信回数制限
- GASとの通信はセーブ・ランキング時のみ（ゲーム中の通信はしない）

**three.jsの扱い**

- r128に固定。新しい版はUMD版がなく、GASの1ファイル配信と相性が悪いため
- build.mjs に `--inline-three` オプションを用意し、指定時はthree.min.jsをHTML内に同梱して外部通信ゼロで動かせるようにする

## 3. ワールド

地図は現行の「140×100タイル（1タイル＝4m、約560m×400m）」を維持し、フェーズ3で東西に拡張できるようにチャンク単位（16×16タイル）で読み込む構造にする。シード値固定で毎回同じ街になる。

**地区とランドマーク**

| 地区 | 特徴 | 主な施設・遊び |
| --- | --- | --- |
| 岐阜市街地 | 高層ビル、磁盤の目の道路 | 銀行、コンビニ、ガンショップ、警察署 |
| 岐阜駅前 | 駅、黄金の信長像、タクシー乗り場 | 電車、タクシー業務、ミッションの起点 |
| 柳ケ瀬 | アーケード商店街 | 服屋、飲食店、ゲームセンター |
| 金華山 | 森とドライブウェイ、山頂に岐阜城 | ヒルクライム、ロープウェイ、展望台 |
| 長良川・河畔 | 川、3本の橋、鵜飼観覧船 | ボート、釣り、鵜飼観覧（夜） |
| 長良 | 住宅街、旅館 | セーフハウス（自宅）、ガレージ |
| 西岐阜の田園 | 田んぼ、農道、農家 | オフロード走行、ストリートレース |
| 東部・岐阜公園 | 公園、博物館風の建物 | ジョギングするNPC、イベント |
| （拡張）大川頭・白川郷風の山村 | 合掌造り風の集落、山道 | 山道レース、雪の天候 |
| （拡張）古い町並み | 飛騨風の商家通り | 観光客NPC、朝市 |

**地形と水**

- 金華山は高さ関数で標高約58m。山頂は城のため平らにならす（現行の mtnH を踏襲）
- 川底は−2.4m、水面は−0.45m。水に入ると「泳ぎ」状態になり、車は水没して停止する
- ロープウェイ：公園→山頂を約60秒で結ぶ（乗れる移動手段）

**建物の中に入れる場所**

室内は「入口で別シーンに切り替え」ではなく、建物の1階部分だけを中が見える作りにする（壁を押し出した店舗メッシュ）。対象はコンビニ、銀行、ガンショップ、服屋、ガレージ、自宅の6種類。

**昼夜と天候**

- 1日＝実時間8分（設定で4～24分に変更可）。夜は窓・街灯・ヘッドライト・篝火が灯る
- 天候は「晴れ／曇り／雨／雷雨／霧／雪（山村のみ）」を確率で遷移。雨は路面が濡れて反射が増え、タイヤのグリップが15%下がる
- 時間帯で交通量と歩行者の層が変わる（朝は通勤、夜は柳ケ瀬に人が集まる）

## 4. 人の動きのリアル化

人は「関節つきの体」「速度に合った歩き方」「周りを見て判断するAI」の3つでリアルにする。外部のアニメーション素材は使わず、コードで全関節を動かす（プロシージャルアニメーション）。

**体の構造（現行7部位 → 13部位）**

- 腰、胸、頭、髪、上腕×2、前腕×2、太もも×2、すね×2、手に持つ小物（スマホ・傘・バッグ）
- 部位ごとにInstancedMeshを1つずつ。合計13ドローコールで最大170人を描画
- 体型パラメータ：身長（1.55～1.90m）、肩幅、体型（細身／普通／がっしり）、服装（スーツ、制服、パーカー、着物などの配色セット）
- 子どものNPCは登場させない（攻撃や事故の対象にしないため）

**アニメーション（pedAnim.js）**

| 動き | 実装の要点 |
| --- | --- |
| 歩き・走り | 待機→歩き→小走り→全力疾走を速度で連続ブレンド。歩幅＝速度×周期で足こすりを防ぐ |
| 関節 | 膝は遊脳期に曲げ、肘は腕振りに合わせて曲げる。腰の上下動と左右のゆれ、胸の逆ひねり |
| 方向転換 | 曲がる速度に上限。走りながら曲がると体を内側に傾ける |
| 坂道・段差 | 左右の足を地形の高さに合わせ、腰の高さを低い方の足に合わせる |
| 視線 | 半径8m以内のプレイヤーや事件に頭を向ける（首の回転上限70度） |
| 仕草 | スマホを見る、電話する、傘をさす、ベンチに座る、立ち話、写真を撮る、ジョギング、犬の散歩 |
| 倒れる | 10点の簡易ラグドール（Verlet積分＋距離拘束）。車にはねられる、爆風、殴られるで使う |
| 起き上がる | ラグドールの最終姿勢から「仰向け／うつ伏せ」を判定し、対応する起き上がり動作へ補間 |
| 怯える・屈む | 頭を抱えてしゃがむ。身を低くして逃げる |

**歩行者AI（crowd.js）**

- 歩道と横断歩道に「歩行レーン」のグラフを張り、目的地（駅、店、公園）へグラフ上を歩く。信号が赤なら横断歩道の前で待つ
- ぶつかり回避：周囲の人を反発（分離）しつつ、1.5秒先の位置を予測して早めによける
- 2～4人のグループで並んで歩く、店の前で列に並ぶ、大道芸人の周りに人垣ができる
- 時間帯と地区で人の層を変える（朝：スーツと学生風の若者、昼：観光客、夜：柳ケ瀬に飲食客、山はハイカー）
- 雨の日は傘を差し、少し速く歩く。軒下やアーケードに集まる

**知覚と反応**

| 刺激 | 知覚範囲 | 反応（性格で分岐） |
| --- | --- | --- |
| 過度な運転、近づく車 | 前方120度・10m | 飛びのく、怒鳴る |
| 殴る・車を奪う | 視界25m | 逃げる／助けに入る／通報する／撮影する |
| 発砲・爆発 | 音で半径60～120m | 悲鳴、屈む、全力で逃げる |
| 武器を構えたプレイヤー | 視界20m | 手を挙げる、後ずさりする |
| 警察のサイレン | 音で40m | 道を開ける、見物する |

- 性格パラメータ：勇敢さ、好奇心、市民意識。1人ずつ乱数で決め、反応の分岐に使う
- 「通報」は電話の仕草から4秒後に手配度システムへ届く。その前に妨害すれば通報されない
- 「撮影」した人がいると、スマホのSNSフィードに動画が投稿される（7章参照）
- 勇敢な人は素手で反撃してくる。武器を持つ一般人は出さない（武器を使うのは警察と敵対勢力のみ）

**LOD（距離による簡略化）**

| 距離 | 更新頻度 | 姿勢計算 |
| --- | --- | --- |
| 30m以内 | 毎フレーム | 全関節＋視線＋足の接地 |
| 30～80m | 2フレームに1回 | 膝・肘なしの簡易歩行 |
| 80m超 | 4フレームに1回 | 位置のみ更新 |

## 5. 車の動きのリアル化

車は「タイヤごとのグリップと荷重移動」で動かし、交通AIは「車線グラフ＋信号＋追従モデル」で滑らかに走らせる。現行の「交差点で瞬間的に向きを変える」動きは廃止する。

**車両物理（vehicles/physics.js）**

- モデル：4輪の簡易レイキャスト車両。車体は剛体（位置・速度・ヨー角速度）、各輪で地形の高さを取り、サスペンションをバネ＋ダンパーで計算
- タイヤ：横滑り角から横力を出す簡易タイヤ式。前後のグリップ配分でアンダー／オーバーステアが自然に出る
- 荷重移動：ブレーキで前に沈み、加速で後ろに沈み、コーナーで外側に傾く（車体のロール・ピッチを描画に反映）
- 駆動方式：FF／FR／4WD。FRはアクセルで尾が流れる、4WDは悪路に強い
- エンジン：回転数と自動変速（5段）。バックは停止後に後退ギア
- 路面：アスファルト＝1.0、濡れた路面＝0.85、草地＝0.6、田んぼ＝0.45、雪＝0.4（グリップ係数）
- ジャンプ：坂の頂上や段差で車輪が浮く。着地でサスペンションが沈む
- 衝突：車同士は質量比で衝撃（インパルス）を分配。壁との衝突は反発係数0.25

**損傷モデル**

- 車体を前・後・左・右の4ブロックに分け、衝突した側の頂点を内側にへこませる（最大15cm）
- 車両HP：50%で白煙、25%で黒煙、0%で消火がなければ5秒後に爆発（コミカルな爆発）
- タイヤパンク（銃やスパイクストリップ）でその輪のグリップが40%になる
- 窓ガラスを割ると破片が飛び、車両盗難時は警報が鳴る

**車種（すべてオリジナル名・オリジナル形状）**

| 分類 | 例 | 最高速度 | 特徴 |
| --- | --- | --- | --- |
| 軽自動車 | ミニワゴン | 110km/h | 小回り、衝突に弱い |
| セダン | セダン、タクシー | 160km/h | 標準 |
| SUV | 4WD SUV | 150km/h | 悪路に強い |
| スポーツ | FRクーペ、スーパーカー | 230～290km/h | 滑りやすい |
| 商用 | バン、軽トラ、トラック、路線バス | 90～130km/h | 重い、押し合いに強い |
| 緊急 | パトカー、救急車、消防車、警察の護送車 | 120～200km/h | サイレン、専用AI |
| 二輪 | スクーター、バイク、電動キックボード | 30～220km/h | 転倒あり（衝突で放り出される） |
| 水上 | ボート、水上バイク | 70km/h | 長良川のみ |

**交通AI（vehicles/traffic.js）**

- 車線グラフ：各車線を節点と辺で表し、交差点内の右左折はベジェ曲線で結ぶ。車は曲線に沿ってハンドルを切る
- 幹線道路（横32・60・74号線、縦50・78号線）は片側2車線に拡幅。遅い車や停車車両があれば車線変更する
- 追従：前車との距離と速度差から加減速を決める追従モデル（IDM）。急停止しない自然な減速
- 信号：全交差点に信号機（3Dモデル）。青→黄→赤を周期30秒で切り替え、歩行者用信号と連動。右折車は対向車を待つ
- 運転手の性格：安全運転／普通／せっかち（車間距離、加速、信号無視率が変わる）
- 反応：進路を塞がれるとクラクション→迴回。発砲を聞くと車を捨てて逃げるか急発進。緊急車のサイレンで左に寄せて停止
- 事故：AI同士も稀に接触し、運転手が降りて口論する小イベントが起きる
- 路線バスとタクシーは停留所・乗り場で停まり、歩行者が乗り降りする
- 駐車車両：一部はNPCが乗り込んで発進し、交通に合流する

**照準と射撃（combat/aim.js）**

- 構え：右クリック（スマホは「構え」ボタン）で肩越しカメラに切り替え、画面中央に照準。スナイパーはスコープ表示
- 照準アシスト：「なし／弱（吸い付き）／強（ロックオン）」を設定で選ぶ。PCは「なし」、スマホは「強」が初期値
- 弾の判定：即着弾（レイキャスト）。人は部位別の当たり箱（頭×2.0、胴×1.0、手足×0.6）、車は向き付きの箱、建物はタイルと高さで判定
- 反動と拡散：連射するほど照準が上に跳ね、弾が散る。しゃがむと拡散が半分
- リロード：Rキー／自動。弾切れで空撃ち音の代わりに画面表示
- ドライブバイ：車やバイクに乗ったまま拳銃・SMGを撃てる
- カバー：Qキーで壁や車の陰に吸い付き、顔だけ出して撃つ
- フォーカス：ゲージを使って数秒間スローモーションにする（7章参照）
- 近接：弱攻撃の3段コンボ、強攻撃、ガード、反撃。当たると相手がよろける

**所持と切り替え**

- 持てる数に上限：近接1、拳钃2、長い銃2（背中に1、もう1つは手に持ったままで周りに見える）、投擲物各種。残りは自宅と車のトランクに保管
- ウェポンホイール：Tab長押し（スマホは武器アイコン長押し）で円形メニュー。開いている間はスロー
- 入手：ガンショップ（購入・弾薬補充・カスタム）、ミッション報酬、警察・敵が落としたものを拾う
- カスタム：スコープ、拡張マガジン、サプレッサー（発砲を聞かれる範囲が1/4）、塗装
- 射撃場：精度チャレンジで武器の技能値が上がり、反動が減る

**爆発と火**

- 爆発は半径内の人・車に距離減衰のダメージと吹き飛ばしを与え、車は連鎖爆発する
- 演出：白い閃光、橙色の球、黒煙、破片、カメラの揺れ。血や人体の欠損は描かない
- 燃えている車は消火器で消せる。消防車が駆けつける

## 8. 手配度・警察、ミッション、経済、セーブ

手配は「犯行→目撃→通報→手配」の順に進み、誰にも見られていなければ手配されない。現行の「犯行した瞬間に★が付く」仕組みはこの流れに置き換える。

通報の途中で妨害するか、捜索エリアの外で見つからずにいれば、手配は解除される。

**犯行と重さ**

| 犯行 | 通報された時の★ | 備考 |
| --- | --- | --- |
| 信号無視・速度超過 | ★（パトカーが目撃した場合のみ） | 一般人は通報しない |
| 駐車車両の盗難 | ★ | 警報が鳴ると周囲が気づく。追跡装置付きの高級車は自動通報 |
| 殴る・車ではねる・車を奪う | ★★ |  |
| 武器を見せて歩く・発砲 | ★★ | 発砲は音で広く知られる |
| 店舗強盗 | ★★★ | 警報ボタンで自動通報。店員を拘束すれば防げる |
| 警官への攻撃 | ★★★ | すでに手配中なら＋1 |
| 銀行強盗・爆発 | ★★★★ |  |

**ヒート（特定されやすさ）**

- 警察が知っている特徴を記録する：服装の色、マスクの有無、使った武器、乗っている車の車種と色、防犯カメラ映像の有無
- 特徴が一致するほど、警察に見つかった時に「視認中」へ切り替わる速さが上がる
- 下げ方：着替える、車を乗り換える、塗装工房に入る、武器をしまう、防犯カメラを壊す、主人公を2人に分けて逃げる
- ヒートは時間でゆっくり下がり、ゲーム内で3日でゼロになる

**警察の対応（★の数ごと）**

| ★ | 出動するもの | 行動 |
| --- | --- | --- |
| 1 | パトカー1～2台 | 停止を呼びかけ、徒歩の警官が逃げる主人公を追いかけて拘束する。発砲しない |
| 2 | パトカー3台＋徒歩の警官 | 体当たりで止める（PIT）。武器を構えたら拳銃で応戦 |
| 3 | パトカー4台＋検問 | 道路封鎖、スパイクストリップ。拳銃とショットガン |
| 4 | 特殊部隊の護送車＋ヘリコプター | ヘリがサーチライトで追跡。屋根やアーケードの下で視界から外れる |
| 5 | 装甲車＋ヘリ2機 | 橋を封鎖。地図全体が捜索エリアになる |

- 星の状態表示：視認中＝白く塗りつぶし、見失った直後＝白く点滅、犯人未特定＝中空き、捜索エリア内＝赤
- 捜索エリア：最後に目撃された地点を中心に円（★×60m）。円の外で指定時間（★×8秒）見つからなければ手配解除。円は移動して絞り込まれる
- 拘束：警官に捕まると「逃れる」ボタン連打の小ゲーム。失敗すると速捕
- 速捕：現金と持っていた武器を失い、警察署から再開。ダウン：現金を失い、治療費を払って病院から再開

**ミッション（systems/missions.js）**

- ミッションはコードではなくデータ（JSON）で定義する。「場所へ行く」「乗る」「持っていく」「倒す」「逃げ切る」「制限時間」などの部品を組み合わせる
- ゆくゆくはスプレッドシートに書いたミッションをGASから読み込めるようにする（社内でミッションを追加できる）

| 種類 | 内容 | 本数（初版） |
| --- | --- | --- |
| 物語 | 2人の主人公が岐阜の裏社会で一旗揚げる全体の筋書き | 12 |
| 強盗・大仕事 | 下見→道具集め→実行→逃走。入り方と逃げ方を選べる | 3 |
| 配達・送迎 | 現行の5本＋タクシー業務（無限） | 6＋無限 |
| レース | ストリート、山道、周回 | 6 |
| サイド | SNSで見つけた事件、困った人を助ける、盗難車の配達依頼 | 15 |

**経済**

- お金は3種類：現金（速捕・ダウンで失う）、口座（安全、ATMとスマホで入出金）、盗品（故買い屋で換金するまで使えない）
- 使い道：武器と弾薬、車の登録と改造、服、物件、修理、給油、罰金
- 収入の目安：配達ミッション1本＝3千～6千円、強盗＝2万～100万円、物件＝1日1千～1万円

**セーブ**

- 保存するもの：進行度、お金（3種）、持ち物と武器、所有車と改造、物件、能力値、信頼度、探索済みの地図、設定
- 自宅で寝ると手動セーブ。ミッション完了時に自動セーブ。スロット3つ
- セーブデータには版番号を持たせ、古い形式を読み込むときは変換関数を通す

## 9. UI・操作

操作は「入力→操作コマンド」の対応表（core/input.js）で1か所にまとめ、キーボード・タッチ・ゲームパッドのどれからでも同じコマンドが出るようにする。設定画面でキーの割り当てを変えられる。

**画面の構成（HUD）**

- 左上：現金、口座残高（変動時のみ）、時刻、天候アイコン
- 右上：円形ミニマップ（進行方向が上、捜索エリア、警察、目的地、探索済み範囲）、その下に手配の★
- 左下：体力、防弾ベスト、フォーカスゲージ（スマホでは左上へ移動）
- 右下：持っている武器と弾数、運転中は速度計と燃料計
- 中央上：ミッションの目標と残り時間。中央下：字幕と操作の案内
- 決め細かい表示はすべて「HUDの表示量：多い／少ない／なし」で切り替えられるようにする

**スマホ画面（ゲーム内の携帯）**

↑キー（スマホは右上の携帯アイコン）で開く。アプリは「地図」「連絡先」「メッセージ」「ギフグラム（SNS）」「クルマスキャン」「銀行」「配車」「カメラ」「設定」の9つ。開いている間もゲームは止まらない（地図と設定のみ一時停止）。

**PCの操作**

| 場面 | 操作 |
| --- | --- |
| 徒歩 | WASD移動、Shift走る、Spaceジャンプ／よじ登り、Cしゃがむ、F車に乗る／奪う、E調べる・話す |
| 戦闘 | マウスで視点、右クリック構え、左クリック攻撃・射撃、Rリロード、Qカバー、G投げる、Tab長押しウェポンホイール、ホイール武器切り替え、Caps Lockフォーカス |
| 運転 | Wアクセル、Sブレーキ・バック、ADハンドル、Spaceサイドブレーキ、Hクラクション／サイレン、Lライト、V視点切り替え、F降りる |
| その他 | ↑スマホ、M地図、Alt主人公の切り替え（円形メニュー）、Esc一時停止 |

マウスの視点操作はポインタロックを使う。GASのページで拒否された場合は「ドラッグで視点」に自動で切り替える。

**スマホの操作**

- 左半分：触った位置が中心になるスティック（徒歩は移動、運転は倒した方向へ向かう）
- 右半分：スライドで視点。ボタンは「攻撃」「構え」「ジャンプ／ブレーキ」「乗る」の4つを場面で入れ替え、使えないボタンは薄くする
- 武器アイコンをタップで次の武器、長押しでウェポンホイール
- ボタンの位置と大きさは設定画面で動かせる。ボタンは親指が届く範囲（画面端から幅の25%以内）に置く
- 縦向きでは「横向きにしてください」を表示して一時停止

**ゲームパッド**：Gamepad APIの標準配置に対応。左スティック移動、右スティック視点、トリガーでアクセル・ブレーキ／構え・射撃。

**設定項目**：画質（高・中・低）、人と車の密度、表現レベル（ふつう／マイルド）、照準アシスト、1日の長さ、視点の感度と上下反転、HUDの表示量、ボタン配置、字幕の大きさ

**準備（最初に1回）**

1. 新しいリポジトリを作り、現行版の index.html と Code.gs を `prototype/` に置く
2. この設計書を `docs/design.md` として保存する（このドキュメントは Markdown で書き出せる）
3. リポジトリ直下に下の CLAUDE.md を置く
4. clasp でGASプロジェクトとつなぐ（`clasp login` → `clasp clone <スクリプトID>`）

**CLAUDE.md（そのまま使える雛形）**

```markdown
# GIFU OPEN ROAD 3D
設計書は docs/design.md。仕様の判断に迷ったら必ず設計書を優先する。

## 制約
- 配信は Google Apps Script（HtmlService）。最終成果物は dist/index.html と gas/Code.gs
- three.js は r128 固定。他の外部ライブラリ、外部画像、外部音声は使わない（すべてコードで生成）
- 実在の企業名、商品名、GTAの名称・ロゴ・UIは使わない
- 血や肉体の欠損は描かない。子どものNPCは出さない
- PC 60fps、中位スマホ30fpsを守る。設計書2章の性能予算を超えない

## 進め方
- 1回の作業で1フェーズだけ実装する。始める前に計画を書いて確認を取る
- 数値パラメータは core/config.js と各定義表に集め、コードに直書きしない
- ロジックは vitest、表示は Playwright（three.jsはローカルに差し替えてテスト）で確認し、スクリーンショットを tests/shots/ に保存する
- 完了時は、受け入れ基準の各項目について確認結果を報告する

## コマンド
- npm run dev   ローカルで起動
- npm run build → dist/index.html
- npm test
- npm run deploy  （build → clasp push）
```
