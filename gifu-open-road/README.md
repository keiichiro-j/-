# GIFU OPEN ROAD 3D

架空の岐阜を舞台にした、ローポリ3Dのオープンワールド・アクション。Google Apps Script（HtmlService）のWebアプリとして配信します。
設計書：[docs/design.md](docs/design.md)

ゲームの処理はすべてブラウザ（three.js r128）で動き、GAS はページの配信とランキングの保存だけを担当します。画像・音声・モデルはすべてコードで生成しているので、外部の素材ファイルはありません。

## GASへの公開手順

1. 依存を入れてビルド
   ```bash
   cd gifu-open-road
   npm install
   npm run build          # three.js を CDN から読む版
   # npm run build:inline # three.js を同梱する版（外部通信なしで起動。約770KB）
   ```
   `gas/index.html` が生成されます（`gas/` が GAS に送るフォルダ）。
2. clasp でGASプロジェクトとつなぐ
   ```bash
   npm i -g @google/clasp
   clasp login
   cp .clasp.json.example .clasp.json   # scriptId を書き換える（新規なら clasp create --type webapp --rootDir gas）
   npm run deploy                       # build → clasp push
   ```
3. GASエディタで「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。アクセスできるユーザーを選んで公開します。
   最初のランキング送信時に、スプレッドシート「GIFU OPEN ROAD ランキング」が自動で作られます。

clasp を使わない場合は、GASエディタで `Code.gs` と HTMLファイル `index`（中身は `gas/index.html` を貼り付け）を作り、`appsscript.json` を合わせれば同じように動きます。

## 実装したもの（初版）

設計書10章のフェーズ0〜7のうち、遊べる形にまとめた初版です。

- **地形**：タイルの角ごとの高さグリッド。西の里山と長良の丘陵は起伏があり、急斜面は岩肌と岩。金華山は尾根と谷のある山肌。地図の外は丘が立ち上がり、遠景に山並み（空の色に溶ける空気遠近法）
- **街**：140×100タイル（1タイル4m）。岐阜市街地・岐阜駅前（黄金の像、タクシー乗り場）・柳ケ瀬（アーケード）・金華山（標高約58m、らせん状のドライブウェイ、山頂の城、ロープウェイ）・長良川（3本の橋）・長良（自宅）・西岐阜の田園・岐阜公園・東部。シード固定で毎回同じ街
- **昼夜と天候**：1日＝実時間8分（4〜24分に変更可）。夜は窓・街灯・ヘッドライトが灯る。晴れ／曇り／雨／雷雨／霧が遷移し、雨は路面のグリップが15%下がる
- **人**：13部位の体（部位ごとのInstancedMesh）、速度で連続ブレンドする歩行サイクル（歩幅＝速度×周期）、歩道グラフ上の移動と信号待ち、グループ歩行、仕草（スマホ・電話・傘）、勇敢さ／好奇心／市民意識による反応の分岐（逃げる・屈む・通報・撮影・反撃）、はねられると倒れて起き上がる／消える、距離によるLOD
- **車**：横滑りと駆動方式（FF/FR/4WD）のある車両物理。ハンドルは切るときゆっくり・戻すとき速く、速度が上がるほど切れ角が減り、滑りを抑える安定化アシスト付き（ドリフトはサイドブレーキで）、坂・ジャンプ、壁と車同士の衝突、損傷（白煙→黒煙→爆発）、パンク、燃料。13車種（すべてオリジナル名）
- **交通AI**：交差点グラフ＋左側通行の車線、交差点はベジェ曲線で曲がる、全交差点の信号（歩行者信号と連動）、IDMの追従、緊急車両に道を譲る、ぶつけられたら止まって再合流
- **戦闘**：武器20種（定義表どおり）、即着弾のレイキャストと部位別判定（頭×2.0）、反動と拡散、照準アシスト3段階、ドライブバイ、投擲・ロケット・粘着爆弾、爆発の連鎖、消火器、所持上限、ウェポンホイール、フォーカス（スロー）、ガンショップ（サプレッサー）、表現レベル「マイルド」で水鉄砲・紙吹雪に差し替え
- **手配と警察**：犯行→目撃→通報（電話の仕草から4秒）→手配。★の4状態（視認中／見失った／未特定／捜索中）、捜索エリア（★×60m）を★×8秒出れば解除、ヒート（服装・マスク・車・色）、★別の出動（★1は降りて拘束、★2以上は降りて発砲、★3以上は走りながら発砲。ヘリ・検問とスパイク）、拘束の連打、逮捕とダウン
- **生活**：スマホ（地図・連絡先・メッセージ・ギフグラム・クルマスキャン・銀行・配車・カメラ・設定の9アプリ）、お金（現金・口座）、ガンショップ・服屋・コンビニ（強盗可）・銀行・病院・ガソリンスタンド・塗装工房・ガレージ（車の登録）・自宅（寝てセーブ、武器の保管）
- **お店と強盗**：コンビニ（おにぎり・弁当・ドリンク・救急セット）、ガンショップ、宝飾店。コンビニ・ガソリンスタンド・宝飾店・銀行は銃を構えて E で強盗（店員が手を挙げ、構え続けている間は警報を押せない。逃げたあとに通報される）
- **車屋・カスタムショップ**：車屋で10車種を購入。カスタムショップでエンジン・ターボ・ブレーキ・タイヤ・サスペンション・装甲・スモークガラス（警察に気づかれにくい）・ネオン・塗装。盗んだ車も登録すれば改造できる
- **不動産と自宅**：6物件（長良の自宅、田園の古民家、東部の一軒家、柳ケ瀬のマンション、駅前タワーマンション、長良川沿いの邸宅）。買った物件を自宅に登録でき、物件ごとのガレージ（2〜8台）に車をしまって出せる。改造と色もそのまま保存
- **ミッション**：データ定義（JSON）の配達5本・ヒルクライムレース・逃走、タクシー業務（無限）
- **セーブ**：端末内に自動1枠＋手動3枠、版番号と変換関数。ランキングはGAS経由でスプレッドシートへ（匿名ID、1分6回まで）
- **その他**：探索した地区だけ地図に表示、初回3秒の簡易ベンチマークで画質を自動選択、縦向きでは「横向きにしてください」

## 設計書との差（今後のフェーズで対応）

- 主人公の2人切り替え・信頼度・能力値、物語ミッション12本と強盗の大仕事（フェーズ6）
- 室内（店舗の1階）、動物、ミニゲーム、拡張エリア（白川郷風の山村・古い町並み）、雪（フェーズ7）
- 車：4輪個別のレイキャストサスペンション、車体のへこみ、二輪車とボート、盗難の小ゲーム（フェーズ2・5）
- 人：10点のVerlet ラグドール（現在は簡易の吹き飛び＋寝かせ）、足の接地IK、カバー（Q）
- 警察：特殊部隊の護送車・装甲車の行動の作り込み

## 開発

```bash
npm test          # ロジックの単体テスト（地図・信号・車両物理・IDM・手配・ミッション・武器・セーブ・歩行）
npm run smoke     # three.js同梱でビルドし、ヘッドレスChromiumで起動確認＋スクリーンショット（tests/shots/）
```

フォルダ構成は設計書2章のとおりです（`src/core` `world` `actors` `vehicles` `combat` `systems` `ui` `fx`）。数値は `src/core/config.js` と各定義表にまとめています。
